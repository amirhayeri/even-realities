G2 HUD Manual

Bio HUD for the gym and Office HUD for the morning, on Even G2 glasses with the R1 ring. Everything the glasses show, every gesture, and every command you run from the Mac.

Basics, both apps

  • Ring only. Taps and swipes on the temples are ignored. Hair and headbands cannot drive the apps.
  • Hello once. The green hello shows for 3 seconds when you open an app, never on a wake. A ring touch skips it.
  • Dark after 15 seconds without input. A ring touch while dark lights the lens where you left off. Looking up lights it too.
  • Exit. Double tap on the ring opens the system exit dialog. The menu also has Exit, even while dark. A ring hold opens the menu only.
  • Menu. Tap and hold the right temple. The menu belongs to the OS, so it works with temple input turned off.
  • Phone. Both apps keep running with the phone locked. The Even app must stay installed and signed in.

Bio HUD

Starts from the Watch app: pick a playlist and a workout type, press Start. The Watch streams heart rate, steps, calories and distance; Spotify starts on the phone; the glasses show it all.

Ring off, Watch on. During a workout swipe left on the Watch for the ring's controls: previous, play/pause, next; Pause and Reset timer; lens brightness (bright, medium, dim). The glasses follow within a few seconds.

Menu, tap and hold the right temple

Pause timer · Resume timer · Reset timer · Brightness · Exit. Pausing the timer also pauses Spotify. Reset restarts the elapsed count only; the Apple workout on the Watch is untouched. Brightness steps the lens tiles bright → medium → dim; the Watch has the same control.

Reading the heart rate tile

  • Under the small heart is the age of the reading: now, then 10-second steps, then minutes.
  • If no reading has arrived for 5 minutes the number gives way to a pulsing heart, with the last value and its age underneath. Check the Watch.
  • Zone bar: Z1 to Z5 of your maximum, the active zone taller with a marker for where in the zone you are.
  • The lens wakes by itself when the zone changes and holds for 5 seconds.

Office HUD

A two-minute briefing. Calendar and mail come from the linked Google account, read live. Texts and missed calls come from an automation on the iPhone. Nothing is stored beyond 24 hours.

Where things come from

  • Mail and calendar: the Google account you linked, read-only. Every calendar ticked in Google Calendar counts. Promotions and Social are skipped.
  • VIP: star a mail in Gmail. That message, and everything from that sender for 30 days, lands in VIP.
  • Texts and missed calls: the iPhone automation "When I receive a notification from Messages or Phone" runs the shortcut Office HUD text, which posts the sender and the words to the Worker. A missed-call banner is filed under Missed.
  • Weather: coordinates in the Worker config.
  • Kept: tap an item while reading it, or Keep for today from the menu. Kept flags expire after 24 hours.

Mac commands

Terminal on the Mac. The repos live at ~/even-realities for Bio HUD and ~/office-hud for Office HUD.

Ship a new build

cd ~/even-realities/app && git pull && npm run release -- "what changed"    # Bio HUD glasses
cd ~/even-realities/endpoint && git pull && npm run deploy                   # Bio HUD Worker
cd ~/office-hud/app && git pull && npm run release -- "what changed"        # Office HUD glasses
cd ~/office-hud/endpoint && git pull && npm run deploy                       # Office HUD Worker

After a glasses release: Even app → Even Hub tab → the app → update. If the release says the Even Hub login expired, run npx evenhub login in that folder first.

Bio HUD control script, from ~/even-realities

app/hud state          # what the Worker holds right now
app/hud start [type]   # start a workout from the Mac (default run), Spotify starts on the phone
app/hud end            # end the workout, Spotify pauses
app/hud pause          # pause or resume the timer
app/hud reset          # restart the elapsed count
app/hud skip           # next track
app/hud prev           # previous track
app/hud play           # play or pause
app/hud hr 142         # fake a heart-rate sample, for testing without the Watch
app/hud playlists      # list your Spotify playlists
app/hud relink         # Spotify login link
app/hud token          # print the token
app/set-token.sh       # rotate the Bio HUD token everywhere

Office HUD checks, from ~/office-hud/endpoint

T=$(grep VITE_HUD_TOKEN ../app/.env | cut -d= -f2); U=https://office-hud-endpoint.amir-e77.workers.dev
open "$U/morning?fresh=1&token=$T"           # the briefing the glasses see, straight from Google
open "$U/morning/prune?token=$T"             # remove blank texts left by manual shortcut runs
open "$U/google/login?token=$T"              # relink Google
curl -s -X POST "$U/morning/text?token=$T" -H 'Content-Type: application/json' -d '{"who":"Test","text":"hello"}'
../tools/make-text-shortcut.sh               # rebuild the iPhone shortcut with the current token, then AirDrop it

When something is off

You seeDo
Nothing on the lens, phone page says page create refusedPut the glasses on, close the app, open it again. Another app may hold the glasses.
Pulsing heart, no numberNo reading for 5 minutes. Open the Watch app; if it says Workouts write is off, Settings → Health → Apps → Bio HUD → allow.
Timer started hours agoMenu → Reset timer, or app/hud end then start again from the Watch.
Spotify plays everywhereThe Worker targets the phone only. Make sure Spotify is open on the phone when the workout starts.
Office Texts stays 0Shortcuts → Automation: the Messages and Phone automation must show Automation on, Notify off, and Run Office HUD text with Input = Shortcut Input.
Office cards empty, "Link Google"Run the relink command above. External Google apps in testing drop the link every 7 days.
Mail older than the newest you seeIt arrived at an account that is not linked, or Gmail filed it under Promotions or Social.
KV write limit exceededOnly on the free Cloudflare plan. The account is on Workers Paid now.
A release fails on version existsRun it again; the script bumps the version itself.
Can't tell what the ring sentOpen the app's page in the Even app: the last six raw inputs are listed under "last input".

Worker routes

All take the token as Authorization: Bearer or ?token=. POST for writes, GET works for testing from a browser.

Bio HUD
GET /stateeverything the glasses poll. lite=1 skips Spotify and weather
POST /workout/start · /workout/end · /workout/resetsession control
POST /healthheart rate, steps, calories, distance from the Watch; replies with the next cadence
POST /pause · /music/next · /music/prev · /music/toggletimer and Spotify
GET /playlists · /spotify/loginWatch picker, one-time link
Office HUD
GET /morningthe briefing, cached 60 s. fresh=1 bypasses the cache
GET /morning/body?id=one message, fetched on demand, never stored
POST /morning/keep · /morning/text · /morning/callkept flag, a text, a missed call
GET /morning/prune · /google/loginclean blank texts, one-time link
